    What this page is

    An offline, self-contained mock-up of the four Nebula Aura themes for PI-Desktop, built by hand in one HTML file. It is not a screenshot of the app and not a live preview of the plugin host: the chat transcript, commits, patches, file tree and JSON fixture are all invented demo data, and the composer is deliberately non-functional.

    Nothing is loaded from the network: no CDN, no webfont, no external image, no build step.

    Palette provenance

    Values copied from the shipped stylesheets, per variant:

    • --ds-*, backdrop, bubble, card, composer, code block, selection — token blocks (lines 5–70), backdrop (84–94), chat rules (100–169).
    • pi.gitlens — 17 colour props mapped onto --ds-* (368–386), identical in all four files.
    • pi.file-manager — literal 19-prop palette plus the JSON syntax hues and the .json-more accent row (407–439).

    Files: nebula-aura-light.css, nebula-aura-dark.css, nebula-aura-violet.css, nebula-aura-midnight.css.

    Type & known deviations

    • Font stack referenced by family name only, exactly as in the theme: Maple Mono NF, 腾祥爱情体简, Consolas, 'Courier New', monospace. No face is embedded or fetched — if neither family is installed locally, this page falls back to Consolas / Courier New / the system monospace face.
    • The real sheet sets one background-image with background-attachment: fixed; here two fixed layers reproduce it so the variant swap can cross-fade.
    • The real app paints its panes opaque, which covers the aura. Preview-only: the three panes are translucent so the glow and star field stay visible.
    • Patch ink on the tinted add/delete rows is a legibility blend of that variant's own success/error token with its ink token; the row tints themselves are the plugin's own 12% rule.
